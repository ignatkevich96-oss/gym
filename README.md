# Дневник тренировок

Простое приложение для себя: записывать тренировки (упражнения, подходы, повторы, вес, заметки) и повторять их одной кнопкой.

Работает в браузере телефона, без сервера и регистрации. Данные хранятся на устройстве; на вкладке «Копия» можно сохранить их в файл и загрузить обратно.

## Как открыть на телефоне

1. В репозитории на GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, выбрать ветку и папку `/ (root)`, нажать **Save**.
2. Через минуту приложение откроется по адресу `https://<имя-пользователя>.github.io/gym/`.
3. Открыть ссылку на телефоне и выбрать «Добавить на главный экран» (Safari: кнопка «Поделиться»; Chrome: меню ⋮).
